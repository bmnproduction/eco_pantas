
## Dukungan multi-platform
Versi terbaru sudah menambahkan responsive layout untuk desktop, laptop, tablet, HP portrait/landscape, layar besar, safe-area notch, dynamic viewport (`svh`/`dvh`), ukuran tombol yang ramah touch, dan `prefers-reduced-motion`.
Challenge 1 juga mendukung alur **tap benda → tap tempat sampah** sehingga tidak wajib drag pada perangkat touch.
